# Kboard Hunik

## 1.0.0
- English (QWERTY) and Arabic (standard layout), Western digits 0-9 on a fixed top row.
- Symbols pages (?123 / =\<) including Arabic punctuation.
- Shift: tap = one letter, double tap = caps lock; automatic capital at the start of a sentence.
- Arabic shift = diacritics row (fatha, damma, kasra, shadda, sukun, tatweel...).
- Long press on a key = alternatives (أ إ آ، é è ê، ١٢٣، پ ڤ گ چ ژ ...). Long press on space / language key = keyboard picker.
- Backspace repeats while held. Enter key follows the field's action (Go / Search / Send / Next / Done).
- Email and URL fields get an English layout with @ or / next to the space bar.
- Setup screen with enable / choose steps, test field, haptics / preview / sound options.
